# Track 02. Your Answers File

The questions every application asks, answered once, plus the ones your field adds, like references and past supervisors. Anything blank means it stops and asks you, never guesses.

**Have ready:** Your salary range and where you're willing to work.

## The prompt

Paste this into Claude Code. Replace anything in [brackets].

```
Make my answers file. Ask me, one at a time, the questions applications always ask: where I'll work, work authorization, sponsorship, start date, salary range, and my links. Then add the ones forms in my field ask, like references and past supervisors. Save them in answers.md. If I skip one, leave it blank and ask me each time it comes up. Never fill a blank with a guess.
```
